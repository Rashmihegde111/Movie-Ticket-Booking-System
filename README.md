# Movie Ticket Booking System

## 1. Project Title

**Movie Ticket Booking System**

A Java console-based application developed using Object-Oriented Programming concepts. The system allows users to view available movies, select a movie, book tickets, calculate the total payment, and view customer and booking details.

---

## 2. Objective

The objective of this project is to develop a simple Movie Ticket Booking System using Java while demonstrating important Object-Oriented Programming concepts such as encapsulation, inheritance, polymorphism, abstraction, interfaces, constructors, method overloading, method overriding, static members, final members, packages, arrays, exception handling, and user input.

---

## 3. Technologies Used

- Java
- Java OOP
- VS Code
- Scanner for user input
- Standard `javac` and `java` commands
- No external libraries required
